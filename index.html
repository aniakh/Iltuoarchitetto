Il tuo accesso

3 report inclusi

Dopo la registrazione ricevi un link personale. Con quel link puoi generare il report completo fino a tre volte.

1

Primo report — provi una direzione di progetto.

2

Secondo report — cambi stile, interventi o stanze.

3

Terzo report — la versione definitiva da portare in cantiere.

🔒

Dopo il terzo, il link smette di generare nuovi report.

Il contatore è visibile dentro lo strumento in ogni momento e vale per il link, non per il browser: cambiare dispositivo o cancellare i dati non lo azzera. Per riattivare l'accesso scrivici.
